## 撮影条件

- Android 15 / API 35 のエミュレーター（1080 × 2400 / 420 dpi）に、検証済みの署名済み release APK（1.0.1 / versionCode 2、SHA-256 `ce9f6080…c913b`）を導入して `adb shell screenrecord` で収録。
- SystemUI のデモモードで時刻を 10:00、電池を満充電、通知アイコンなしに固定。
- 加工は ffmpeg のカット・連結・字幕の焼き込みのみ。画面の内容そのものは加工していません。
- 収録した映像は可変フレームレートのため、切り出し前に 30 fps 固定へ変換しています。

## Play Console への登録

プロモーション動画は **YouTube 動画の URL** で指定します。動画ファイルを直接アップロードすることはできません。

1. この MP4 を YouTube にアップロードします。公開または限定公開にします（非公開だと Play 側から参照できません）。
2. 広告が入らない設定にします。収益化を有効にしていると広告が挿入され、審査で指摘される場合があります。
3. Play Console の「ストアの設定」→「メイン ストアの掲載情報」→「プロモーション動画」に、`https://www.youtube.com/watch?v=…` の形式で URL を貼り付けます。短縮 URL やプレイリスト、タイムスタンプ付きの URL は避けます。
4. 動画はスクリーンショットの前に再生されます。冒頭の数秒で内容が伝わるようにしています。
