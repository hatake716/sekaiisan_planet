# 検証記録（2026-09-07）

前版の記録: [1.0.0](validation/1.0.0.md)

## 不具合と修正の確認

- ピン消失: 地平線判定の固定余白 `0.02` が、最小高度 `0.0019` より大きく、拡大時に画面中央のピンまで除外していた。実際の地平線に対する可視判定へ変更。
- 極付近の停止: 緯度を ±89 度に制限し、ドラッグ・ピンチを緯度経度の差分で計算していた。球面点と四元数の回転へ変更し、緯度制限を撤廃。慣性と移動アニメーションにも同じ回転を使用。
- 修正前に回帰テストを実行し、最大拡大時のピン、地平線より手前のピン、極の中心表示の 3 テストが失敗することを確認。修正後は通過。
