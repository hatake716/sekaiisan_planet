# 地球儀で見る世界遺産 プライバシーポリシー

制定日: 2026年9月6日 / 開発者: hatake716

本アプリは、開発者のサーバーへの個人情報の収集・送信を行いません。アカウント登録、広告、アクセス解析、位置情報の取得はありません。世界遺産の写真・説明・地球画像はアプリ内に同梱しています。

## 端末内に保存する情報

ブックマーク、閲覧済みの世界遺産、最後に見ていた地球儀の位置を端末内に保存します。開発者には送信しません。アプリのストレージを消去するかアンインストールすると削除されます。OS のアプリデータのバックアップは無効です。

## 外部ページの閲覧

Wikipedia、YouTube、Wikimedia Commons、ライセンスのページ、UNESCO のページを開いた場合は、それぞれのサービスに通信します。IP アドレス、端末・ブラウザー情報、Cookie、閲覧情報などの取り扱いは、各サービスのプライバシーポリシーに従います。アプリ内 WebView はウェブページの表示に Cookie・ローカルストレージを利用する場合があります。外部ブラウザーで開くこともできます。

- [Wikimedia プライバシーポリシー](https://foundation.wikimedia.org/wiki/Policy:Privacy_policy)
- [Google / YouTube プライバシーポリシー](https://policies.google.com/privacy)
- [UNESCO プライバシーポリシー](https://www.unesco.org/en/privacy-policy)

## 権限と共有

インターネット権限は上記ページの閲覧に使用します。カメラ、マイク、連絡先、GPS、写真ライブラリーへの権限は要求しません。共有ボタンは、選択した世界遺産の名称とリンクを、ユーザーが選んだアプリに渡します。

## お問い合わせ・変更

[GitHub のお問い合わせ窓口](https://github.com/hatake716/sekaiisan_planet/issues)から連絡できます。個人情報を含む内容は公開 Issue に記載しないでください。本方針を変更した場合は、このページとアプリ内表示を更新します。
